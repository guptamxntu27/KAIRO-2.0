# KAIRO Anime Streaming Platform

KAIRO ek Flask-based Anime Streaming Web Application hai jise GitHub aur Railway par deploy karne ke liye design kiya gaya hai.

## Features:
- Secure Admin Authentication (Password Change option ke sath)
- Anime posters, descriptions manage/add/delete karna
- Hindi 🇮🇳 aur English 🇬🇧 servers (Video Links) toggle karne ka support
- Persistent SQLite Database Setup
- Direct Railway Deployment Support

## Setup Locally:
1. Requirements install karein:
   ```bash
   pip install -r requirements.txt
   ```
2. App run karein:
   ```bash
   python app.py
   ```
3. Default Admin Credentials:
   - **Username:** `admin`
   - **Password:** `admin123`
